# Standards & Process

Team conventions, governance, and process guides for the Agent Assurance All Towers project.

*For page creation conventions, see [Wiki Governance](/Standards-%26-Process/Wiki-Governance).*

## Pages

- [Wiki Governance](/Standards-%26-Process/Wiki-Governance) — Rules for creating, naming, and structuring wiki pages: the three-page triad, folder vs. flat sibling rules, header format, contracts and decisions conventions, and the mandatory parent index rule.
- [Boards Governance](/Standards-%26-Process/Boards-Governance) — Azure DevOps Boards conventions: work item hierarchy, title formats, description templates, tag taxonomy, sprint cadence, and Definition of Done.
- [Git & Branching](/Standards-%26-Process/Git-%26-Branching) — Branch naming, commit message format, PR conventions, and merge strategy.
- [CI-CD](/Standards-%26-Process/CI-CD) — Pipeline design, formal guarantees, numbered decision log, and developer guide for the `assurance-platform` CI/CD system.
