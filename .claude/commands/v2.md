Browse and read repositories in the **V2** Azure DevOps account (AGENTASSURANCE01).

The CLI is `python tools/repos.py --org AGENTASSURANCE01` in this directory. Auth uses `az login` — no PATs.

## Operations

- `python tools/repos.py --org AGENTASSURANCE01 --project "<project>" list` — list all repos in a project
- `python tools/repos.py --org AGENTASSURANCE01 --project "<project>" browse <repo> [--path /] [--branch <branch>]` — list files/dirs
- `python tools/repos.py --org AGENTASSURANCE01 --project "<project>" read <repo> <path> [--branch <branch>]` — print file contents
- `python tools/repos.py --org AGENTASSURANCE01 --project "<project>" branches <repo>` — list branches
- `python tools/repos.py --org AGENTASSURANCE01 --project "<project>" commits <repo> [--branch <branch>] [--top 20]` — recent commits

## Available projects

- `Agent Assurance All Towers` — assurance-platform, assurance-scanner-bundle, assurance-client-kit, portable-harness-rehearsal
- `AGENTASSURANCE01` — intake-api, intake-ui, aks-sample, azdo-agent
- `AgentGovernance` — AgentGovernance

Default project from `.env` is `Agent Assurance All Towers`. Pass `--project` to target a different one.

## Instructions

Translate the user's request ($ARGUMENTS) into the right command(s) and run them. This is the **active V2** org where all greenfield builds happen. When the user doesn't specify a project, use the default from `.env`.
