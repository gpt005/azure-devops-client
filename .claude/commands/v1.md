## Operations

- `python tools/repos.py --org AccLLM --project "AI Refinery" --tenant e0793d39-0939-496d-b129-198edd916feb list` — list all repos
- `python tools/repos.py --org AccLLM --project "AI Refinery" --tenant e0793d39-0939-496d-b129-198edd916feb browse <repo> [--path /] [--branch <branch>]` — list files/dirs
- `python tools/repos.py --org AccLLM --project "AI Refinery" --tenant e0793d39-0939-496d-b129-198edd916feb read <repo> <path> [--branch <branch>]` — print file contents
- `python tools/repos.py --org AccLLM --project "AI Refinery" --tenant e0793d39-0939-496d-b129-198edd916feb branches <repo>` — list branches
- `python tools/repos.py --org AccLLM --project "AI Refinery" --tenant e0793d39-0939-496d-b129-198edd916feb commits <repo> [--branch <branch>] [--top 20]` — recent commits
